# 🚀 Bilim ve Teknoloji Bülteni (Android APK)

Bu proje, **Bilim, Teknoloji, Yapay Zeka ve Uzay** alanındaki güncel gelişmeleri canlı tarayıp tek dokunuşla telefonunuza getiren bağımsız bir Android uygulamasıdır (`.apk`).

---

## 📲 APK Dosyasını GitHub Üzerinden İndirme (3 Basit Adım)

Bu depoda **GitHub Actions Otomasyonu** kuruludur. Dosyaları GitHub'a yüklediğinizde, GitHub sizin için arka planda APK dosyasını otomatik olarak derler ve telefonunuza indirilebilir hale getirir!

### 1. Adım: GitHub'da Yeni Depo (Repository) Açın
1. [github.com](https://github.com) sitesine gidin ve hesabınıza giriş yapın.
2. Sağ üstteki **`+`** simgesine tıklayıp **"New repository"** seçin.
3. Depo adına `bilim-teknoloji-bulteni` yazın ve **"Create repository"** butonuna basın.

### 2. Adım: Bu Klasördeki Dosyaları Yükleyin
* Yeni açılan repo sayfasında **"uploading an existing file"** (mevcut bir dosya yükle) bağlantısına tıklayın.
* Bu klasördeki (`bilim_teknoloji_apk`) tüm dosyaları ve klasörleri (`app`, `.github`, `build.gradle`, `settings.gradle` vb.) sürükleyip bırakın ve alttaki **"Commit changes"** butonuna basın.

### 3. Adım: Otomatik Derlenen APK'yı Telefonunuza İndirin
1. Dosyaları yüklediğiniz anda üst menüdeki **"Actions"** sekmesine gidin.
2. **"Build Android APK"** işleminin başladığını göreceksiniz (~2 dakika sürer).
3. İşlem bittiğinde sağ taraftaki **"Releases"** bölümüne gidin (veya Actions içindeki **Artifacts** kısmına bakın).
4. **`BilimTeknolojiBulteni.apk`** dosyasına dokunarak doğrudan telefonunuza indirin ve kurun! 🎉
